# Dani Macarrão na Chapa

Landing page desenvolvida para divulgação da loja Dani Macarrão na Chapa, com foco em responsividade, desempenho e experiência do usuário.

## Site Online

https://danimacarraonachapa.com.br

## Tecnologias Utilizadas

- HTML5
- CSS3

## Funcionalidades

- Layout responsivo
- Cardápio digital
- Navegação intuitiva
- Botão para pedido via WhatsApp, Uai Rango e Instagram
- Otimização de imagens e desempenho

## Objetivo do Projeto

Criar um site leve e funcional para apresentação de um negócio real.

## Aprendizados

Durante o desenvolvimento deste projeto foram aplicados conceitos de:

- Responsividade
- Estruturação de layout
- Performance web
- Deploy e domínio personalizado
- Organização visual e UX
